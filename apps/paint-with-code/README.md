# Paint with Code

Single-user playground for [p5.brush](https://github.com/acamposuribe/p5.brush) watercolor sketches. The code is the artefact: edit a stroke, re-render, download a PNG.

Inspired by [Training AI to Paint with Code](https://surya.website/rling-qwen-to-paint-with-code). This demo is the playground, not the RL trainer.

## Run

Local (Vite `base` is `/paint-with-code/` so assets match Pages):

```bash
bun install
bun run dev
```

Open **http://localhost:5173/paint-with-code/** — not the site root.

Live (Cloudflare Pages project `tech-demos`): **https://tech-demos.pages.dev/paint-with-code/**
